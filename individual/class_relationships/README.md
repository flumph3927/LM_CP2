# Project name
***
![Image of code while running](location of image in folders)
A class manager that allows you to manage student grades and see class summaries and statistics.

## How to use
***
1. Run main.py
2. Select option (add student is reccomended for first choice)
3. Continue selecting until done, then select exit

## Project features details
***
- Student grade managment
- Specific student viewing
- Multiple class overviews including information on all students; student academic standing; class average, best, and worst grade; and total number of students
- Saves all information to file upon exit
