
# Project name
***
![Image of code while running](location of image in folders)
This project creates either a serpinski triangle fractal or an unnamed square fractal using the python module turtle.

## How to use
***
1. Select to create a serpinski triangle, square fractal, or exit
2. If generating a fractal, enter background color
3. Enter fractal depth
4. Fractal generates. Saves it as given file name to given file path, or defaults to LM_CP2 folder.

## Project features details
***
- Serpinski triangle: Generates a serpinski triangle with a depth of between 1 and 6
- Square fractal: Generates an unnamed square fractal with a depth of between 1 and 6
- Allows changing the background color of the fractal
- Allows saving fractals as .eps files, but may not save with background color
